# GuzStudio Portfolio

Статическое портфолио веб-разработчика: чёрный фон, крупный Onest, лаймовые действия и коллаж реальных проектов. Галерея содержит семь кейсов; задача, решение и результат раскрываются через нативный `details`.

## Файлы

| Путь | Назначение |
| --- | --- |
| `index.html` | Разметка, CSS, языковые словари и небольшой JavaScript |
| `PRODUCT.md` | Продуктовый контекст и ограничения; предположения явно отмечены |
| `DESIGN.md` | Актуальные токены и правила реализованного дизайна |
| `.impeccable/design.json` | Метаданные, движение и образцы компонентов для панели дизайна |
| `assets/*.webp` | Реальные скриншоты проектов |
| `assets/fonts/` | Локальные файлы Onest и лицензия |

Сборка и npm-зависимости не нужны. Шрифты загружаются с того же сервера, что и сайт. Основная навигация, ссылки и раскрытие кейсов работают без JavaScript; скрипт добавляет смену языка, активную секцию и копирование email.

## Локальный запуск

Из корня проекта:

```bash
python3 -m http.server 8000
```

Открыть [localhost:8000](http://localhost:8000).

## Изображения

Используйте реальные скриншоты в WebP. В галерее изображения обрезаются сверху через `object-fit: cover`; обычное соотношение сторон — 1.6, у первого большого кейса на настольном экране — 1.45. Указывайте размеры изображения, `loading="lazy"` и `decoding="async"` для галереи; hero загружается сразу.

Пример конвертации:

```bash
cwebp -q 76 shot.jpg -o assets/project.webp
```

## Языки

EN / RU / KK переключаются на клиенте. Словарь `T` в конце `index.html` хранит значения в порядке `[ru, en, kk]`; элементы связаны с ним через `data-i`. Новый текст добавляйте сразу на трёх языках.

Разметка по умолчанию английская. Приоритет выбора: `?lang=en|ru|kk` в URL → сохранённый язык в `localStorage` → английский. Пример локальной ссылки: [русская версия](http://localhost:8000/?lang=ru). При переключении меняются `lang`, заголовок страницы и тексты словаря; описание и Open Graph в исходной разметке английские.

## Публикация

Разместите `index.html` и всю папку `assets/` на статическом хостинге. Отдельный сервер приложения не требуется. Перед публикацией проверяйте ссылки, все три языка, раскрытие кейсов, клавиатурный фокус и мобильную ширину.
