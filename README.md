# Portfolio

Личный сайт-визитка — статическая одностраничная страница без сборки и зависимостей.

## Что где лежит

| Путь | Назначение |
| --- | --- |
| `index.html` | вся страница: разметка, стили и скрипты в одном файле |
| `DESIGN.md` | визуальная спецификация: палитра, типографика, компоненты, анимации, правила адаптива |
| `assets/*.webp` | скриншоты проектов для блока «Избранные работы» |
| `.claude/skills/web-design` | скилл, по которому собрана спецификация и вёрстка |

`DESIGN.md` — источник правды по оформлению. Любая правка стилей сначала проверяется на соответствие ему:
один акцентный цвет, ноль хардкод-цветов в коде, шрифты только с кириллицей, всё интерактивное имеет hover и focus.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Обновить скриншот проекта

Скриншоты сняты в 1440×900 при `deviceScaleFactor: 1.5`, уменьшены до 1600px по ширине и переведены в WebP:

```bash
cwebp -q 76 shot.jpg -o assets/имя-проекта.webp
```

Кадр — первый экран проекта, соотношение сторон 16:10 (карточка обрезает по `object-fit: cover`).

## Языки

EN / RU / KK переключаются на клиенте: словарь `T` в конце `index.html`, элементы помечены
атрибутом `data-i`. Порядок значений в массиве — `["русский", "english", "қазақша"]`.

По умолчанию страница открывается на английском: в разметке лежит английский текст,
`<html lang="en">`, английские `title`, `description` и og-теги. Русский и казахский
накладываются скриптом при загрузке.

Язык выбирается по порядку: параметр `?lang=en|ru|kk` в URL → сохранённый в `localStorage`
→ английский. Ссылку на конкретный язык можно давать прямо:
`https://stuzzhin.netlify.app/?lang=ru`.

Добавляя текст на страницу, добавляй ключ в `T` сразу с тремя значениями — иначе
при переключении останется английская строка из разметки.

## Деплой

Любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages.

Для GitHub Pages: Settings → Pages → Source: `main` / `root`.
