Boost Marine

boostmarine.ru ↗
Обслуживание и продажа катеров — сайт + внутренняя система
Задача
Заявки терялись в мессенджерах, вести блог было некому, владелец не видел, откуда приходят клиенты.
Решение
Сайт с каталогом услуг, админ-панель с воронкой заявок и аналитикой по источникам, генерация черновиков статей для блога через LLM с ручной модерацией.
Результат
Все обращения в одном месте с историей, контент выходит регулярно без отдельного копирайтера.

Dianafarm Group

dianafarm.group ↗
Международный консалтинг — многоязычный корпоративный сайт
Задача
Компания работает в ЕС, ОАЭ и Болгарии, услуги разбиты по отраслям — прежний сайт не давал клиенту быстро найти своё направление.
Решение
Структура «отрасль → услуга» с отдельными посадочными страницами, мультиязычность, единая форма заявки с маршрутизацией по направлению.
Результат
Сайт закрывает несколько рынков одним ресурсом, страницы услуг можно вести как рекламные посадочные.
